# Data classification

Public: published program text. Internal: IDs, configuration, workflow metadata. Personal: name, birth date, contact, guardian, academic history. Sensitive: CCCD. Restricted financial: account holder/number and transfer details. Secrets: sessions, recovery codes and encryption/provider keys.

Sensitive/restricted data is minimized, encrypted, masked, excluded from URLs/logs/analytics/list APIs and browser persistence. Reveal/export requires purpose, re-auth where applicable and append-only audit.
